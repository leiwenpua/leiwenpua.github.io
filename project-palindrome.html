DNA Palindrome Finder

Python HTML5 CSS3 JavaScript

Project Background

It was a group project during my academic studies. The primary objective was to build a functional web-based platform capable of identifying Inverted Repeats (palindromic sequences) in raw genomic data—a critical task for identifying restriction enzyme recognition sites and understanding DNA structural stability.

My Key Responsibilities

  • 01.
    Core Algorithm Development: Independently developed a raw Python script to execute pattern matching for inverted repeats. Implemented base-pairing logic (A-T, C-G) and sliding window searches to detect sequences that are identical to their reverse complements.
  • 02.
    Backend Workflow Orchestration: Engineered the server-side logic (Python) to handle the data lifecycle: receiving raw DNA strings via the UI, processing them through the search engine, and formatting outputs for front-end rendering.
  • 03.
    System Integration & Deployment: Collaborated with front-end developers to ensure seamless API integration. Orchestrated the final deployment workflow, verifying that the algorithmic engine was correctly interfaced with the web environment to provide real-time sequence analysis for users.

Platform Demonstration

Detection Strategy: Finding DNA Palindromes

1 Dual-Stream Substring Mapping

The algorithm processes both the Sense and Antisense strands. By applying a reverse-complement transformation to the antisense strand, the search for biological palindromes is optimized into a structured string-matching problem.

2 Parametric Spacer Search

Beyond direct repeats, the system calculates a dynamic offset to detect Inverted Repeats with Spacers. This logic is critical for identifying potential Stem-Loop structures in genomic data.

3 Coordinate-based De-duplication

To ensure data integrity, a recursive filter compares hit coordinates (Start, End). It automatically retains the longest, most biologically significant motif while pruning redundant sub-matches.

Algorithm Concept

1
Exhaustive Sliding Window

The algorithm iterates through every possible substring Lminsub> → Lmaxsub> to ensure zero false negatives in motif detection.

2
Length-Based Hashing

Subsequences are categorized into hash maps by length, optimizing the comparison phase by only matching strings of identical dimensions.

3
Linear Coordinate Constraints

To find "Spaced Palindromes," the algorithm applies a strict geometric constraint: the distance between repeats must satisfy the User-Defined Spacer Gap.
